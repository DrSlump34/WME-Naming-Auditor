Source : API Découpage administratif de l'État (geo.api.gouv.fr), contours issus d'Admin Express (IGN) et du Code Officiel Géographique de l'INSEE — open data permissif. À ne pas confondre avec les jeux de contours dérivés d'OpenStreetMap, en ODbL.
Volume : environ 3 Mo et une dizaine de secondes par département. Plusieurs départements cochés produisent un seul fichier fusionné — utile puisque le script remplace ses contours à chaque chargement.
Propriétés produites : nom et code (INSEE), directement exploitables.
